Contexto:

Uma academia deseja desenvolver um programa para calcular o de seus alunos.

O programa deverá solicitar:
Peso, em quilogramas;
Altura, em metros.
Depois, deverá calcular:

IMC = peso / (altura * altura)

Em seguida, o programa deverá classificar o resultado:
IMC menor que 18,5 → Abaixo do peso
IMC de 18,5 até 24,9 → Peso normal
IMC de 25,0 até 29,9 → Sobrepeso
IMC de 30,0 até 34,9 → Obesidade grau I
IMC de 35,0 até 39,9 → Obesidade grau II
IMC maior ou igual a 40 → Obesidade grau III
Desafio para o aluno

O programa deverá solicitar o peso e a altura do usuário, calcular o IMC e apresentar sua classificação.
